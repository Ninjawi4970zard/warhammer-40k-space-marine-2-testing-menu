## 📖 Overview

*Testing Menu* allows you to test various features, practice against enemies, or just have fun. This mod adds an in-game menu that allows you to summon enemies and equipment, add/remove modifiers, and perform other actions.

---

## ⚡ Features

- Enemy Spawner, Modifiers, Equipment Spawner, Testing Arena (`F1`–`F5`).

---

## 📥 Installation

1. Download the archive via the button above
2. Extract `setup_0.7.exe` from the archive
3. Run `setup_0.7.exe` **as Administrator**
4. Wait for unpacking to finish
5. Launch the game
